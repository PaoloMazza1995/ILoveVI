**ILoveVI** (`ilovevi.com`) is an open-source companion app built by fans, for fans, designed to guide the community through the anticipation and post-launch journey of **Grand Theft Auto VI**.

The app goal is to provide a clean, fast, tracker-free, and community-driven tool to explore Leonida, follow verified news and leaks, and share guides.

---

## 🗺️ Key Features

*   📍 **Interactive Map:** An open-source interactive map to track collectibles, points of interest, and secrets across the game world.
*   🔍 **Verified Leak Tracker:** A curated section to separate real leaks from hoaxes, backed by concrete evidence and community analysis.
*   📚 **Community Guides & Wiki:** Quick guides, deep dives, and translations of official news.
*   💬 **Fan Hub / Forum:** A clean, moderated space to discuss theories, strategies, and connect with other players.

---

## 🚀 Tech Stack

*This project is built with Kotlin Multiplatform and Jetpack Compose Multiplatform, a multiplatform framework that allows native code to be run on both Android/iOS/Web platforms. No other frameworks are allowed in this repo*

## 🤝 How to Contribute

Since this project is **open source**, we need everyone's help to make it the best GTA VI companion app out there! You can contribute in many ways:

1. **Reporting bugs or suggesting new features** by opening an [Issue](../../issues).
2. **Submitting Pull Requests** to fix bugs or improve the codebase (please check out [CONTRIBUTING.md](CONTRIBUTING.md) first).
3. **Updating content**, guides, or map coordinates as new information about the game unfolds.
